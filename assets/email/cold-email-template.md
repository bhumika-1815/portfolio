## Gmail setup

1. In Gmail, open Settings (gear) → See all settings → General → Signature. Create one with the three lines above and link each word.
2. Compose a new email, paste the text, and put your cursor where the banner goes.
3. Click Insert photo → Web address (URL) → paste the banner's live URL (works after you push), or Upload the PNG.
4. Click the image, then the link icon (Cmd+K), and paste the portfolio URL.
5. Save it as a template: Settings → Advanced → enable Templates. Then in compose, ⋮ → Templates → Save draft as template.
